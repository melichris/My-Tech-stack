# My-Tech-stack

A small collection of learning projects and experiment folders. This repository currently contains a Vue 3/Vite learning project under the `Vue-fundametals` folder.

## Projects

- `Vue-fundametals` — starter project demonstrating Vue 3 + Vite, TypeScript, and simple components.

## Quickstart

Prerequisites: Node.js (v16 or newer) and npm or pnpm.

```bash
cd "Vue-fundametals"
npm install
npm run dev
```

Common scripts (run inside `Vue-fundametals`):

- `npm run dev` — run development server
- `npm run build` — build for production
- `npm run preview` — preview the production build

## Repo structure

- `Vue-fundametals/` — Vue 3 + Vite project
  - `src/` — source files (components, App.vue, main.ts)
  - `public/` — static assets
  - `package.json`, `vite.config.ts`, `tsconfig.json`
