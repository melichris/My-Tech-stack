# Dev Training

Collection of small training and reference projects for learning modern frontend patterns.

Projects

- [Vue-fundametals](Vue-fundametals/README.md) — Vue 3 + Vite learning project with TypeScript and example components.
- [TICKET-02-recipe-book](TICKET-02-recipe-book/README.md) — Recipe Management reference implementation (Vue 3, Composition API, composable-based state).
- [TICKET-03-expense-tracker](TICKET-03-expense-tracker/expense-tracker/README.md) — Expense tracker demo project (Vite + Vue 3).

Quickstart (general)

Prerequisites: Node.js 16+ and npm or pnpm.

To run a project locally, from this repository root:

```bash
cd <project-folder>
npm install
npm run dev
```

Type-checking

For Vue + TypeScript projects, use `vue-tsc` to type-check `.vue` files:

```bash
npx vue-tsc --noEmit
```
